## 📋 1. Sobre o Projeto

O **Achego** é uma aplicação desenvolvida com o propósito de proporcionar uma experiência intuitiva, segura e acolhedora na conexão entre usuários e profissionais de apoio. O projeto integra o planejamento de desenvolvimento técnico e serve como base principal para portfólio[cite: 1.2].

---
## ✨ 2. Funcionalidades Principais

* **Gestão de Perfis:** Cadastro e distinção de perfis (Pacientes, Psicólogos e Administradores).
* **Agendamento Inteligente:** Fluxo simplificado para marcação e acompanhamento de consultas.
* **Segurança e Autenticação:** Proteção de rotas e dados sensíveis dos usuários.
* **Interface Intuitiva:** Foco na acessibilidade, acolhimento e navegação fluida.

---
## 🛠️ 3. Tecnologias Utilizadas

O ecossistema técnico do projeto abrange as seguintes tecnologias e ferramentas:

* **Backend:** Java (Spring Boot), Node.js (Express, TypeScript)
* **Banco de Dados:** PostgreSQL, SQL
* **Controle de Versão:** Git e GitHub
* **Arquitetura & Boas Práticas:** REST APIs, Arquitetura em Camadas (Controller, Service, Repository)
* **Ferramentas de Apoio:** IntelliJ IDEA, Postman, Canva (Prototipação)
